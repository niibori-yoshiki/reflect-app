# ビジネス日記アプリ

AIが対話形式で今日の仕事を深掘りし、ビジネス英語フレーズの学習とスキル可視化を行う振り返りツールです。

## 機能

- AIとの対話による日記作成（3〜4往復で自動まとめ）
- 会話内容からビジネス英語フレーズを3つ抽出
- 穴埋め形式のクイズ
- レベル・経験値システム
- スキル分析（プロジェクト管理、交渉、プレゼンなど）
- 過去の振り返り履歴をサイドバーに表示
- 全データはローカルJSON保存

## セットアップ

### 1. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. 環境変数の設定

```bash
cp .env.example .env
```

`.env` ファイルを開き、Anthropic APIキーを設定してください:

```
ANTHROPIC_API_KEY=sk-ant-your-actual-key-here
```

APIキーは https://console.anthropic.com/ から取得できます。

### 3. アプリの起動

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。

## 使い方

1. アプリが起動すると、AIが「今日のお仕事はいかがでしたか？」と質問します
2. 今日の仕事について自由に話してください
3. 3〜4回の会話後、自動的にまとめモードに移行します
4. まとめでは以下が表示されます:
   - 今日の振り返り要約
   - 学んだこと
   - ビジネス英語フレーズ3つ
   - スキルポイント・獲得経験値
5. クイズに挑戦してボーナスXPを獲得できます

## データ保存場所

すべてのデータは `data/` ディレクトリにローカル保存されます:

- `data/profile.json` - レベル・経験値・スキル情報
- `data/diaries/YYYY-MM-DD.json` - 日ごとの振り返り記録
