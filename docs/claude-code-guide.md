# Claude Code 活用ガイド

Claude Codeを業務で活用するためのガイドです。

---

## Claude Code とは

Anthropicが提供するCLI（コマンドライン）ベースのAIコーディングアシスタントです。
ターミナルやVSCodeから直接利用でき、以下のような作業を効率化できます。

- コードの生成・修正・レビュー
- ファイル検索・分析
- Git操作（コミットメッセージ生成、PR作成）
- ドキュメント作成
- バグの調査・修正

---

## 基本的な使い方

### 起動

```powershell
# プロジェクトディレクトリで起動
cd ~\Documents\your-project
claude
```

### よく使うコマンド

| コマンド | 説明 |
|---|---|
| `/help` | ヘルプを表示 |
| `/clear` | 会話履歴をクリア |
| `/compact` | 会話を要約して圧縮 |
| `/cost` | セッションのAPI使用コストを表示 |
| `/model` | 使用モデルを切り替え |

### VSCode統合

VSCodeのターミナルからも `claude` コマンドで起動可能です。
プロジェクトフォルダを開いた状態で使うと、コードベース全体を理解した上で支援してくれます。

## CLAUDE.md の活用

プロジェクトのルートに `CLAUDE.md` ファイルを置くと、Claude Codeが自動的に読み込みます。
プロジェクト固有のルールやコンテキストを記載しておくと効果的です。

### 例：WMSプロジェクト用 CLAUDE.md

```markdown
# プロジェクト概要
ナカシマヘルスフォース向けWMSシステム

## 技術スタック
- バックエンド: （使用技術）
- データベース: （使用DB）
- フロントエンド: （使用技術）

## コーディング規約
- 変数名は日本語コメントを付ける
- SQLは大文字で記述
- コミットメッセージは日本語で書く

## 注意事項
- 本番DBへの直接アクセスは禁止
- 顧客情報を含むデータはコミットしない
```

## コスト管理

Claude CodeはAPI利用に応じて課金されます。

### コスト確認方法

```
/cost
```

### コスト削減のコツ

- `/compact` で会話が長くなったら圧縮する
- 大きなファイルを丸ごと読ませるより、関連部分を指定する
- 明確で具体的な指示を出す（やり直しを減らす）

---

## セキュリティ上の注意

- **APIキーを絶対にGitにコミットしない**（`.env`に記載し、`.gitignore`に追加）
- **顧客データ・個人情報をプロンプトに含めない**
- **社外秘の情報の取り扱いに注意する**（Anthropicのデータポリシーを確認）
- 生成されたコードは必ず人間がレビューする
